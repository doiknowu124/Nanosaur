## 📖 Overview
<a id="overview"></a>

**Nanosaur** is an engaging third-person action game for **Windows**, developed by **Pangea Software Inc.** In this action-packed title, players control a time-traveling dinosaur on a mission to retrieve eggs from five different species within a thrilling 20-minute time limit before an impending asteroid impact. The latest version of **Nanosaur** is filled with exciting features, offering a complete gaming experience with all functionalities available.

Explore a prehistoric world, utilize a unique 'temporal compass' to navigate through time portals, and engage in dynamic gameplay that combines strategy and combat. Download the latest version now and embark on your adventure!
